# 천안시 직원 후생복지 — 인터랙티브 웹 프레젠테이션

원본 PPT 10장 내용을 유지한 정적 웹 프레젠테이션입니다. 별도 서버, 데이터베이스, 빌드 과정이나 외부 JavaScript 라이브러리가 필요하지 않습니다.

## 사용하기

- `index.html`을 더블클릭하면 로컬에서 바로 볼 수 있습니다.
- 상단 번호 또는 하단 이전/다음 버튼으로 이동합니다.
- 키보드 방향키, PageUp/PageDown, 스페이스바, Home/End를 지원합니다.
- 데스크톱에서는 마우스 휠로 이동할 수 있습니다.
- 모바일에서는 좌우 스와이프로 슬라이드를 바꾸고, 상하 스크롤로 긴 내용을 볼 수 있습니다.
- 오른쪽 위 격자 아이콘으로 전체 슬라이드를 볼 수 있습니다.
- URL 뒤에 `#slide-4`처럼 붙여 특정 장으로 바로 연결할 수 있습니다.

## GitHub Pages 배포

1. GitHub에서 새 공개 또는 Pages를 지원하는 저장소를 생성합니다.
2. 이 ZIP의 **내용물 전체** (`index.html`, `style.css`, `script.js`, `assets/`)를 저장소 최상위에 올립니다. ZIP 파일만 올리면 안 됩니다.
3. 저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
4. 브랜치 `main`, 폴더 `/(root)`를 선택하고 **Save**를 누릅니다.
5. 배포 완료 후 `https://사용자명.github.io/저장소명/` 주소로 접속합니다.

## 편집 안내

- 문구는 `script.js` 맨 위 `slides` 배열에서 수정합니다.
- 색상과 배치는 `style.css`에서 수정합니다.
- 원본 PPT에서 추출한 캐릭터 그림은 `assets/slide-01.webp`부터 `slide-10.webp`에 들어 있습니다.
- `slides.json`은 별도로 편집/관리하기 위한 원본 데이터 사본입니다. 실제 실행에는 `script.js` 안에 데이터가 내장돼 있으므로 `file://`에서도 정상 작동합니다.
- 외부 폰트와 CDN 없이 시스템 한글 폰트를 사용합니다.

원본 슬라이드의 검토·제안 표현은 확정된 복지제도로 바꾸지 않고 그대로 유지했습니다.
